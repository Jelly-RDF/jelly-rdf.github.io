# Performance benchmarks

[Jelly-JVM]({{ jvm_link() }}) 4.0.0 was benchmarked against the serialization formats built into Apache Jena and Eclipse RDF4J:

- **[Jelly-RDF](rdf.md)** – RDF triples and quads, compared with N-Triples / N-Quads, Turtle / TriG, RDF/XML, JSON-LD, RDF/JSON, Jena's binary formats, and RDF4J Binary.
- **[Jelly-SPARQL](sparql.md)** – SPARQL query results, compared with the XML, JSON, and TSV results formats, Jena's binary formats, and RDF4J Binary.
