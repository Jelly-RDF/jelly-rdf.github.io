# Performance benchmarks

[Jelly-JVM]({{ jvm_link() }}) 4.0.0 was benchmarked against the serialization formats built into Apache Jena and Eclipse RDF4J, and [pyjelly]({{ python_link() }}) 0.9.0 against the formats built into RDFLib:

- **[Jelly-RDF](rdf.md)** – RDF triples and quads, compared with the formats in Apache Jena, Eclipse RDF4J, and RDFLib.
- **[Jelly-SPARQL](sparql.md)** – SPARQL query results, compared with the formats in Apache Jena, Eclipse RDF4J, and RDFLib.
- **[Jelly-RDF 1.1 vs 1.2](rdf-1-1-vs-1-2.md)** – Jelly-RDF 1.2 (the default in Jelly-JVM 4.0.0 and pyjelly 0.9.0) compared with Jelly-RDF 1.1.
